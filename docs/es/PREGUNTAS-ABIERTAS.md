# Preguntas abiertas

- **El orden de los números después del león.** El primero está medido; el
  resto no. El tipo se escribe de forma indirecta y no está seguido.
- **Las tres tablas de móviles** (`0x54C5`, `0x5A6F`, `0x5F8F`): 32 pares de
  (bandera, altura) cada una. Se sabe cuál usa cada atracción, no qué
  significa cada bandera.
- **Los contadores de tanda de `0xE059`/`0xE05A`**: cada dieciséis
  apariciones bajan de golpe doce, o dieciséis si venían de `0x20`. Qué
  dificultad regulan no está medido.
