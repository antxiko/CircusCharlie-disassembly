# Open questions

- **The order of the acts after the lion.** The first one is measured; the
  rest are not. The type is written indirectly and has not been followed.
- **The three moving-object tables** (`0x54C5`, `0x5A6F`, `0x5F8F`): 32
  (flag, height) pairs each. Which act uses which is known; what each flag
  means is not.
- **The batch counters at `0xE059`/`0xE05A`**: every sixteen appearances they
  drop twelve at once, or sixteen if they came from `0x20`. What difficulty
  they regulate has not been measured.
